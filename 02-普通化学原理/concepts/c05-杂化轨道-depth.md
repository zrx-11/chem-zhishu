## 为什么甲烷是正四面体，而不是平面正方形

这是化学里最经典的一个"为什么"。碳的基态电子排布是 1s²2s²2p²，2s 轨道有两个电子，2p 有三个轨道但只填了两个电子。如果直接用这些轨道成键，会得到两种不同类型的 C—H 键：一个来自 2s，三个来自 2p。但实验测出甲烷的四个 C—H 键完全等价，键角都是 109.5°。矛盾出在哪？

### 第一步：先看"不杂化"会怎样

2s 轨道是球形，2p 轨道是哑铃形，沿 x、y、z 三个方向伸展。用它们与 H 的 1s 重叠：
- 2s 与 H 1s 重叠，形成一种键；
- 2p 与 H 1s 重叠，形成另一种键，方向沿坐标轴。

这样会得到 1 个 s 型键 + 3 个 p 型键，键长、键能都不同。实验上四个键一模一样，所以这个模型不对。

### 第二步：轨道可以"混合"

量子力学允许同一原子中能量相近的轨道线性组合。2s 和 2p 能量接近（同一层），可以组合成四个新轨道：

$$\psi_{sp^3} = c_1\psi_{2s} + c_2\psi_{2p_x} + c_3\psi_{2p_y} + c_4\psi_{2p_z}$$

每个新轨道含 1/4 s 成分、3/4 p 成分，四个轨道完全等价。这就是 sp³ 杂化。

### 第三步：为什么是四面体

四个等价轨道要互相远离。三维空间中，让四个向量两两夹角最大的排列，是指向正四面体的四个顶点，夹角 109.47°。

可以用向量验证：正四面体中心到顶点，任意两个向量点积为 −1/3，所以 cosθ = −1/3，θ = 109.47°。这不是巧合，是"四个等价方向最大分离"的唯一解。

### 第四步：为什么键角会变小

NH₃ 也是 sp³ 杂化，但有一对孤对电子占据一个杂化轨道。孤对电子只受 N 一个核吸引，电子云更靠近核、更"胖"，对相邻成键电子对排斥更强，把三个 N—H 键往下压，键角从 109.5° 降到 107°。

H₂O 有两对孤对，压缩更明显，键角 104.5°。

### 第五步：乙烯为什么是平面

乙烯 C₂H₄ 的每个碳连两个 H 和一个 C，共 3 个 σ 键、0 个孤对，价层电子对数 3 → sp² 杂化。三个 sp² 轨道在同一平面内，夹角 120°。每个碳还剩一个未杂化的 p 轨道，垂直于该平面，两个 p 轨道肩并肩形成 π 键。所以乙烯的六个原子共平面，双键不能旋转。

### 边界与常见误用

杂化是一种"模型"，不是物理上真的先把轨道混合再成键。它提供的是可计算的、与实验一致的解释。对过渡金属配合物，要用 d 轨道参与杂化（dsp²、sp³d² 等），情况更复杂，不能直接套 s/p 的规则。
