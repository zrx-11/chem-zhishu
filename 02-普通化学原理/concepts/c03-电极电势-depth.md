## Nernst 方程是怎么来的

先别背公式，先问一个问题：为什么浓度会影响电极电势？

### 第一步：把电极反应写成半反应

以 Cu²⁺/Cu 电极为例：

$$\mathrm{Cu^{2+} + 2e^- \rightleftharpoons Cu(s)}$$

这个半反应的"驱动力"来自两件事：Cu²⁺ 得电子的趋势（由 E° 衡量），以及当前 Cu²⁺ 的浓度。浓度越高，Cu²⁺ 越"想"得电子，电极电势越高。

### 第二步：用热力学把浓度接进来

第 4 章给过：ΔG = ΔG° + RTlnQ。电化学里，ΔG 与电势的关系是

$$\Delta G = -nFE$$

n 是转移电子数，F 是法拉第常数 96500 C/mol，E 是电池电动势。把两式联立：

$$-nFE = -nFE^\circ + RT\ln Q$$

两边除以 −nF：

$$E = E^\circ - \frac{RT}{nF}\ln Q$$

这就是 Nernst 方程的一般形式。25 ℃ 时，RT/F = 0.0257 V，换常用对数乘 2.303：

$$E = E^\circ - \frac{0.0592}{n}\lg Q$$

### 第三步：Q 到底怎么写

Q 的形式与平衡常数一致：生成物活度幂之积除以反应物活度幂之积，纯固体和纯液体取 1。

对 Cu²⁺ + 2e⁻ → Cu，Q = 1/[Cu²⁺]。代入：

$$E = E^\circ + \frac{0.0592}{2}\lg[\mathrm{Cu^{2+}}]$$

注意符号变成了加号：因为 Cu²⁺ 在反应物侧，浓度在分母，lg(1/c) = −lg c，负负得正。浓度每降为 1/10，E 下降约 0.0296 V。

### 第四步：数字算一遍

E°(Cu²⁺/Cu) = +0.34 V。当 [Cu²⁺] = 0.001 mol/L：

$$E = 0.34 + \frac{0.0592}{2}\lg(0.001) = 0.34 + 0.0296\times(-3) = 0.34 - 0.0888 = 0.251\ \text{V}$$

浓度降了 1000 倍，电势只降了 0.089 V。这说明 E° 是主项，浓度是修正项。也解释了为什么"金属活动性顺序"在标准浓度附近够用，一旦浓度极端偏离，顺序可能翻转。

### 第五步：为什么能斯特方程能判断方向

若 E电池 > 0，则 ΔG = −nFE < 0，反应自发。E电池 = E正 − E负，所以 E° 大的电对作正极。浓度改变时，比较的是实际 E，不是 E°。

### 边界

Nernst 方程假设活度可用浓度近似，适用于稀溶液。浓溶液、强电解质、非理想体系要用活度系数修正。它也不处理动力学：E > 0 只说明热力学允许，反应可能因活化能高而很慢。
