# 陌生方程式诊断题库

题目取自《陌生方程式的书写查缺补漏》讲义，答案与解析由本课程补全。作答时先自己写，再看解析。

## 信息型化学方程式

### Q1. Na₂S₂O₃ 在酸性溶液中分解，生成黄色沉淀和刺激性气体，写出离子方程式。
**答案**：S₂O₃²⁻ + 2H⁺ → S↓ + SO₂↑ + H₂O
**解析**：S 的平均价为 +2，一部分歧化为 0 价（S）和 +4 价（SO₂）。补 H⁺ 和 H₂O 后检查：S 2=2，O 3=2+1，H 2=2，电荷 −2+2=0。

### Q2. Na₂S₂O₃ 被 Cl₂ 氧化为 SO₄²⁻，写出离子方程式。
**答案**：S₂O₃²⁻ + 4Cl₂ + 5H₂O → 2SO₄²⁻ + 8Cl⁻ + 10H⁺
**解析**：S +2→+6，每个 S 失 4e，两个 S 共失 8e；Cl₂ 每个 Cl 得 1e，需要 4 个 Cl₂。左边电荷 −2，右边 2×(−2)+8×(−1)+10×(+1) = −2，平。

### Q3. NaBH₄ 与水反应生成 NaBO₂ 和 H₂，写出化学方程式。
**答案**：NaBH₄ + 2H₂O → NaBO₂ + 4H₂↑
**解析**：B 从 −5? 不必纠结形式价态，按原子守恒：Na1、B1、O2、H 4+4=8，右边 H₂ 4×2=8。

### Q4. 硫与热的 NaOH 溶液反应，产物中硫的最高价为 +4，写出离子方程式。
**答案**：3S + 6OH⁻ → 2S²⁻ + SO₃²⁻ + 3H₂O
**解析**：S 歧化：2 个 S 降到 −2，1 个 S 升到 +4。电荷左边 −6，右边 2×(−2)+(−2) = −6。

## 工艺流程与图像型

### Q5. NaClO₃ 与盐酸反应生成 ClO₂，写出化学方程式。
**答案**：2NaClO₃ + 4HCl → 2ClO₂↑ + Cl₂↑ + 2NaCl + 2H₂O
**解析**：Cl 从 +5 降到 +4（ClO₂），部分 Cl 从 −1 升到 0（Cl₂）。2 个 ClO₃⁻ 得 2e，2 个 Cl⁻ 失 2e，电子守恒。

### Q6. 足量铁粉与稀硝酸反应生成 NO，写出化学方程式。
**答案**：Fe + 4HNO₃(稀) → Fe(NO₃)₃ + NO↑ + 2H₂O
**解析**：Fe 0→+3 失 3e；N +5→+2 得 3e。1:1 配平，再补 3 个 NO₃⁻ 和 2 个 H₂O。

## 离子方程式

### Q7. 酸性溶液中 Ca(NO₂)₂ 分解产生 NO，写出离子方程式。
**答案**：3NO₂⁻ + 2H⁺ → 2NO↑ + NO₃⁻ + H₂O
**解析**：N 歧化：2 个 N 从 +3 降到 +2，1 个 N 升到 +5。电荷左边 −3+2=−1，右边 −1，平。

### Q8. H₃AsO₃ 被 MnO₂ 氧化为 H₃AsO₄，写出离子方程式。
**答案**：H₃AsO₃ + MnO₂ + 2H⁺ → H₃AsO₄ + Mn²⁺ + H₂O
**解析**：As +3→+5 失 2e，Mn +4→+2 得 2e，1:1。补 2H⁺ 和 1H₂O 后检查原子与电荷。

### Q9. K₄[Fe(CN)₆] 爆炸分解，生成 KCN 和三种稳定单质，写出化学方程式。
**答案**：K₄[Fe(CN)₆] → 4KCN + Fe + 2C + N₂↑
**解析**：三种单质是 Fe、C、N₂。K 4→4，Fe 1→1，C 6=4+2，N 6=4+2。

### Q10. 碱性条件下 ClO⁻ 将 CN⁻ 氧化为 CNO⁻，写出离子方程式。
**答案**：CN⁻ + ClO⁻ → CNO⁻ + Cl⁻
**解析**：C +2→+4 失 2e，Cl +1→−1 得 2e，1:1。原子和电荷都平。

### Q11. 酸性条件下 CNO⁻ 继续被 ClO⁻ 氧化为 N₂ 和 CO₂，写出离子方程式。
**答案**：2CNO⁻ + 3ClO⁻ + 2H⁺ → N₂↑ + 2CO₂↑ + 3Cl⁻ + H₂O
**解析**：N −3→0 失 3e×2=6e；Cl +1→−1 得 2e×3=6e。O 左边 2+3=5，右边 4+1=5。

## 电极反应式

### Q12. 丙烷燃料电池以熔融碳酸盐为电解质，写出正极反应式。
**答案**：O₂ + 2CO₂ + 4e⁻ → 2CO₃²⁻
**解析**：正极 O₂ 得电子，在碳酸盐环境中与 CO₂ 结合生成 CO₃²⁻。电荷 −4 = −4，O 原子 2+4=6=2×3。

### Q13. 电解 Ce³⁺ 再生 Ce⁴⁺，写出生成 Ce⁴⁺ 的电极反应式。
**答案**：Ce³⁺ − e⁻ → Ce⁴⁺
**解析**：Ce 从 +3 升到 +4，失 1 个电子，发生在阳极。

## 元素化合物创新题

### Q14. 镁着火不能用 CO₂ 灭火，写出化学方程式。
**答案**：2Mg + CO₂ →(点燃) 2MgO + C
**解析**：Mg 0→+2 失 4e，C +4→0 得 4e。2:1 配平。

### Q15. AgCl 白色沉淀遇 KBr 转化为淡黄色沉淀，写出离子方程式。
**答案**：AgCl(s) + Br⁻ → AgBr(s) + Cl⁻
**解析**：沉淀转化，Ksp(AgBr) 更小。AgCl 难溶，写化学式不拆。

### Q16. 完成酸性条件下 MnO₄⁻ 氧化 C₂O₄²⁻ 的离子方程式。
**答案**：2MnO₄⁻ + 5C₂O₄²⁻ + 16H⁺ → 2Mn²⁺ + 10CO₂↑ + 8H₂O
**解析**：Mn +7→+2 得 5e×2=10e；每个 C +3→+4 失 2e，5 个 C₂O₄²⁻ 失 10e。补 16H⁺ 和 8H₂O。

### Q17. NH₃ 与 NO₂ 反应生成 N₂ 和 H₂O，写出化学方程式。
**答案**：8NH₃ + 6NO₂ → 7N₂ + 12H₂O
**解析**：N 从 −3 和 +4 归中到 0。设 NH₃ 系数 8、NO₂ 6，N 8+6=14，右边 7N₂=14。

### Q18. 少量 NH₃ 与过量 Cl₂ 反应生成酸性气体和 NCl₃，写出化学方程式。
**答案**：NH₃ + 3Cl₂ → NCl₃ + 3HCl
**解析**：N −3→+3 失 6e，3 个 Cl₂ 共得 6e。NCl₃ 中 N、Cl 均满足 8 电子结构。

### Q19. 酸性条件下 Cr₂O₇²⁻ 氧化 SO₃²⁻ 为 SO₄²⁻，写出离子方程式。
**答案**：Cr₂O₇²⁻ + 3SO₃²⁻ + 8H⁺ → 2Cr³⁺ + 3SO₄²⁻ + 4H₂O
**解析**：Cr +6→+3 得 3e×2=6e；S +4→+6 失 2e×3=6e。补 8H⁺ 和 4H₂O。

### Q20. CeO₂ 在稀硫酸和 H₂O₂ 作用下生成 Ce³⁺，写出化学方程式。
**答案**：2CeO₂ + H₂O₂ + 3H₂SO₄ → Ce₂(SO₄)₃ + O₂↑ + 4H₂O
**解析**：Ce +4→+3 得 1e×2=2e；H₂O₂ 中 O −1→0 失 2e。补硫酸成盐，检查 O 和 H。

## 计算题

### Q21. 用 0.04000 mol/L EDTA 滴定 25.00 mL 镍溶液，消耗 25.50 mL，样品 2.6826 g 配成 250 mL。求 NiSO₄·nH₂O 的 n。
**答案**：n = 6
**解析**：25.00 mL 中 Ni²⁺ 为 0.04000×0.02550 = 1.020×10⁻³ mol；250 mL 中为 1.020×10⁻² mol。摩尔质量 = 2.6826/1.020×10⁻² = 263.0 g/mol。NiSO₄ 为 154.75，差值 108.2，除以 18.02 得 6。
