# 速查表

## 五步
1. 读信息：反应物、产物线索、环境、价态
2. 判类型：化学式 / 离子式 / 电极式
3. 定产物：价态、环境、元素守恒
4. 配平：电子 → 原子 → 电荷
5. 检查：原子、电荷、电子、符号

## 环境补项
| 环境 | 补什么 |
|---|---|
| 酸性 | H+ 和 H2O |
| 碱性 | OH- 和 H2O |
| 熔融碳酸盐 | CO3^2- 和 CO2 |

## 高频产物
| 元素 | 常见产物 |
|---|---|
| Mn | Mn2+（酸性）、MnO2（中性/弱碱） |
| Cr | Cr3+（还原）、CrO4^2-（碱性氧化） |
| S | SO2、SO4^2-、S |
| N | NO、NO3-、N2 |
| C | CO2、CO3^2- |
