# 速查表

## 常见反应
| 反应 | 方程式 |
|---|---|
| 氯气与碱 | Cl2 + 2NaOH → NaCl + NaClO + H2O |
| 钠与水 | 2Na + 2H2O → 2NaOH + H2↑ |
| 过氧化钠 | 2Na2O2 + 2H2O → 4NaOH + O2↑ |
| 铝与碱 | 2Al + 2NaOH + 2H2O → 2NaAlO2 + 3H2↑ |
| 铝热 | 2Al + Fe2O3 → Al2O3 + 2Fe |
| 合成氨 | N2 + 3H2 ⇌ 2NH3 |
| 氨催化氧化 | 4NH3 + 5O2 → 4NO + 6H2O |
