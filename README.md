# 化学知枢 · 从零基础到大学化学

一套可以直接部署到 GitHub Pages 的化学学习系统。总入口 `index.html`，五本书各自也能单独打开。

## 目录结构

| 路径 | 说明 |
|---|---|
| `index.html` | 总学习手册，单文件，含跨书导航、各书章节、测验、抽认卡、术语、搜索、进度 |
| `index.md` | 总入口的 Markdown 版导航 |
| `00-跨书总览/` | 学习路线、视频配套、跨书概念映射、综合检验 |
| `01-零基础入门/` | 10 章 + 3 概念 + 20 测验 + 20 卡片 |
| `02-普通化学原理/` | 12 章 + 5 概念（4 个带深度推导）+ 24 测验 |
| `03-简明无机化学/` | 4 章 + 1 概念 + 8 测验 |
| `04-有机化学基础/` | 4 章 + 1 概念（带深度推导）+ 8 测验 |
| `05-陌生方程式诊断/` | 1 章方法 + 21 题诊断 + 五步法概念 |
| `.nojekyll` | 关闭 Jekyll，保证中文名与 `_work` 目录正常托管 |
| `_build/` | 生成脚本、验证脚本、验证报告、界面截图 |

每本书目录内还有 `manifest.json`、`SKILL.md`（总纲）、`chapters/`、`concepts/`、`glossary.md`、`patterns.md`、`cheatsheet.md`、`flashcards.md`、`quiz.md`、`学习伴侣.html`。

## 怎么用

- 双击 `index.html`，或部署后访问 Pages 地址。
- 顶部标签切换书籍；左侧是学习路径、章节、概念、测验、抽认卡、术语、模式库、速查表。
- 进度存在浏览器 localStorage，换设备不同步；同一台机器刷新不丢。
- 公式用 KaTeX 渲染，需要联网；断网时公式显示源码，文字与导航不受影响。

## 部署到 GitHub Pages

```bash
# 1. 把本项目全部文件放到仓库根目录
cd <仓库目录>
git add -A
git commit -m "化学知枢：多书整合学习系统"
git push origin main

# 2. 仓库 Settings → Pages → Source: Deploy from a branch
#    Branch: main，目录: / (root) → Save

# 3. 等 1~2 分钟，访问
#    https://<用户名>.github.io/<仓库名>/
```

若仓库还没有初始化：

```bash
git init
git add -A && git commit -m "化学知枢"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

## 内容来源与边界

- 主线教材：《普通化学原理（第4版）》（华彤文等）、《简明无机化学（第2版）》（宋天佑）、《基础有机化学（上册）》（邢其毅等）、《五彩绳 高中化学基础知识大全》。
- 自编材料：`基础概念.pdf`（8 大类概念清单）、`陌生方程式的书写查缺补漏.docx`（题型讲义）。
- 扫描版教材没有文字层，按章读图后重写，不逐页抄原文；所有例题与数值算例都重新核对过。
- 教材内容版权归原作者与出版社，本系统只作个人学习用途，请勿商用或公开传播原文扫描件。

## 已知限制

- 公式与 Mermaid 图依赖 CDN；完全离线时降级为源码。
- 进度只存在当前浏览器，不跨设备。
- 第 3、4 本基于扫描版教材整理，覆盖面以"能串成网"为准，不追求原书全部细节。
