# 化学知枢 · 零基础到无机及分析化学

一套可以直接部署到 GitHub Pages 的化学学习系统。总入口 `index.html`，六本书各自也能单独打开。

主线是 `03-无机及分析化学`（考纲主线，13 章）和 `04-无机及分析化学题库`（78 题）；`01-零基础入门` 补语言，`02-普通化学原理` 当原理参考书，`05-有机化学基础`、`06-陌生方程式诊断` 当拓展。

## 怎么用

- 双击 `index.html`，或部署后访问 Pages 地址。
- 顶部标签切换书籍；左侧是学习路径、章节、概念、测验、抽认卡、术语、模式库、速查表。
- 备考顺序：`03` 第 0 章 → `03` 第 4–10 章 → `04` 78 题 → 错题回 `03` 对应章节。
- 进度存在浏览器 localStorage，换设备不同步；同一台机器刷新不丢。
- 公式用 KaTeX 渲染，需要联网；断网时公式显示源码，文字与导航不受影响。
- 知识图谱的 vis-network 已内嵌在页面里，断网也能画。桌面显示固定分栏关系图（左列章节按学习顺序自上而下，右列概念）；手机窄屏自动切成按章节排列的路线图，避免整张图缩到看不清。

## 部署到 GitHub Pages

```bash
# 1. 把本项目全部文件放到仓库根目录
cd <仓库目录>
git add -A
git commit -m "化学知枢：无机及分析化学主线"
git push origin main

# 2. 仓库 Settings → Pages → Source: Deploy from a branch
#    Branch: main，目录: / (root) → Save

# 3. 等 1~2 分钟，访问
#    https://<用户名>.github.io/<仓库名>/
```

若仓库还没有初始化：

```bash
git init
git add -A && git commit -m "化学知枢"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

## 内容来源与边界

- 考纲主线：《无机及分析化学》（韩忠霄、孙乃有）、《无机及分析化学学习指导与习题解析》（马凤霞、王秀彦），均为扫描版，OCR 目录后按章重写。
- 原理参考：《普通化学原理（第4版）》（华彤文等）。
- 基础与拓展：《简明无机化学（第2版）》（宋天佑）、《基础有机化学（上册）》（邢其毅等）、《五彩绳 高中化学基础知识大全》、`基础概念.pdf`、`陌生方程式的书写查缺补漏.docx`。
- 扫描版教材没有文字层，按章读图后重写，不逐页抄原文；所有例题与数值算例都重新核对过。
- 教材内容版权归原作者与出版社，本系统只作个人学习用途，请勿商用或公开传播原文扫描件。

## 已知限制

- 公式与 Mermaid 图依赖 CDN；完全离线时降级为源码。
- 知识图谱不依赖 CDN，但窄屏下是文字路线图，不是缩放后的关系图；要拖拽视图请用桌面或横屏。
- 进度只存在当前浏览器，不跨设备。
- `03` 是按考纲重写的教学版，不是教材全文复刻；覆盖面以考点和计算题型为准。
