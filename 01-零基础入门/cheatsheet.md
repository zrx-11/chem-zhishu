# 速查表

## 核心公式
| 场景 | 内容 |
|---|---|
| 物质的量 | n = m/M |
| 微粒数 | n = N/N_A，N_A = 6.02×10²³ |
| 气体体积 | n = V/V_m，标况 V_m = 22.4 L/mol |
| 浓度 | c = n/V溶液 |

## 常见化合价
| 元素 | 价态 |
|---|---|
| H | +1（金属氢化物中 -1） |
| O | -2（过氧化物 -1） |
| Na、K | +1 |
| Ca、Mg、Ba | +2 |
| Al | +3 |
| Fe | +2、+3 |
| Cu | +2（少数 +1） |
| Cl | -1（氯化物中） |
| S | -2（硫化物中） |

## 离子方程式拆写
- 拆：强酸、强碱、可溶盐
- 不拆：难溶物、气体、水、弱电解质、氧化物、微溶物悬浊液
