基础概念​
文科零基础、为大学化学补课专用​
必须理解 + 记忆：​
一、化学入门通用基础概念​
1. 物质基础分类概念​
1. 元素：具有相同质子数的一类原子总称​
2. 单质：由同一种元素组成的纯净物​
3. 化合物：由两种及以上元素组成的纯净物​
4. 纯净物：只有一种组成成分，固定化学式​
5. 混合物：多种物质混合，无固定化学式​
6. 氧化物：只由氧元素 + 另一种元素组成的化合物​
7. 酸：水溶液电离出的阳离子全部是​
​
H+
8. 碱：水溶液电离出的阴离子全部是​
​
OH−
9. 盐：由金属阳离子（铵根）和酸根阴离子构成​
2. 微观粒子基础​
1. 原子：化学变化中最小粒子​
2. 分子：保持物质化学性质的最小微粒​
3. 离子：原子得失电子后形成的带电粒子（阳离子带正电，阴离子带负电）​
4. 质子（正电）、中子（不带电）、核外电子（负电）​
5. 核电荷数 = 质子数 = 原子序数​
3. 化学符号规范概念​
1. 元素符号：通用国际简写​
2. 化学式：用元素符号表示物质组成​
3. 化合价：元素在化合时表现出的得失电子数目​
4. 化学方程式：用化学式表示化学反应的式子，遵循质量守恒​

三、化学反应基础分类概念​
1. 化合反应：多种物质生成一种物质​
2. 分解反应：一种物质拆分生成多种物质​
3. 置换反应：单质 + 化合物 → 新单质 + 新化合物​
4. 复分解反应：两种盐 / 酸碱互相交换成分，发生反应（生成沉淀 / 气体 / 水）​
5. 氧化反应：物质失去电子，化合价升高​
6. 还原反应：物质得到电子，化合价降低​
7. 氧化剂：得电子、被还原；还原剂：失电子、被氧化​
8. 氧化还原反应：存在化合价升降的化学反应​
四、离子反应 & 水溶液基础概念​
1. 电解质：在水溶液 / 熔融状态可以导电的化合物（酸、碱、绝大多数盐）​
2. 非电解质：水溶液和熔融态都不导电的化合物（蔗糖、乙醇等有机物）​
3. 强电解质：完全电离（强酸、强碱、绝大多数盐）​
4. 弱电解质：部分电离（弱酸、弱碱、水）​
5. 电离方程式：表示电解质拆成自由移动离子的式子​
6. 离子反应：溶液中离子之间发生的反应​
7. 离子方程式：删减不参与反应离子后的简化反应式​
8. 溶解度：一定温度下，100g 水最多溶解的溶质质量​
9. 沉淀：溶解度极小，无法完全溶解的固体生成物​

五、元素周期表与周期律基础概念​
1. 周期：元素周期表横向行，代表电子层数​
2. 主族：周期表纵向主列，代表最外层电子数​
3. 金属性：原子失去电子的能力（越强越容易形成阳离子）​
4. 非金属性：原子得到电子的能力（越强越容易形成阴离子）​
5. 原子半径：原子的相对大小​
6. 化学键：相邻原子之间强烈的相互作用力​
◦离子键：阴阳离子之间作用力（金属 + 非金属典型组合）​
◦共价键：原子之间共用电子对（非金属和非金属之间）​
六、化学反应原理极简基础（无机、物化前置）​
1. 化学反应速率：化学反应进行的快慢程度​
2. 可逆反应：同一条件下，既能正向进行，也能逆向进行的反应​
3. 化学平衡：可逆反应正逆反应速率相等，各物质浓度不再改变的状态​
4. 勒夏特列原理：平衡体系受到外界改变（浓度、温度、压强），平衡会向着减弱这种改变的方向移
动​
5. 放热反应：反应过程向外释放热量​
6. 吸热反应：反应过程需要持续吸收外界热量​
七、有机化学基础概念​
1. 有机物：绝大多数含碳化合物（CO、CO₂、碳酸盐等归为无机物）​
2. 烃：只由碳、氢两种元素组成的有机物​
◦烷烃：单键饱和烃​
◦烯烃：含碳碳双键​
◦炔烃：含碳碳三键​
3. 官能团：决定有机物化学性质的原子 / 原子团​
必备识别：羟基 (-OH)、羧基 (-COOH)、碳碳双键、酯基 (-COO-)​
4. 取代反应：有机物某个原子 / 基团被其他基团替换​


5. 加成反应：不饱和键打开，直接结合小分子​
6. 酯化反应：羧酸和醇反应生成酯和水​
八、基础物质结构极简概念​
1. 电子层：核外电子分层排布​
2. 稳定结构：最外层 8 电子（第一层为 2 电子）结构​
3. 分子式：表示分子原子个数​
4. 结构式：画出原子之间共价键连接方式​
