# 术语表

| 术语 | 白话定义 | 章节 |
|---|---|---|
| 纯净物 | 只由一种物质组成、有固定化学式的体系 | ch01 |
| 电解质 | 在水溶液或熔融状态下能导电的化合物 | ch06 |
| 离子方程式 | 删去旁观离子后只保留实际参加反应离子的方程式 | ch06 |
| 氧化剂 | 得电子、化合价降低、被还原的物质 | ch07 |
| 还原剂 | 失电子、化合价升高、被氧化的物质 | ch07 |
| 物质的量 | 表示微粒集合份数的物理量，单位 mol | ch05 |
| 摩尔质量 | 1 mol 物质的质量，单位 g/mol | ch05 |
| 官能团 | 决定有机物化学性质的原子或原子团 | ch10 |
