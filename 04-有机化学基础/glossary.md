# 术语表

| 术语 | 白话定义 | 章节 |
|---|---|---|
| 键线式 | 省略碳和碳氢键、只画碳骨架与官能团的结构式 | ch01 |
| 同分异构体 | 分子式相同、结构不同的化合物 | ch01 |
| 构象 | 单键旋转形成的不同空间排列，不断键即可互变 | ch02 |
| 马氏规则 | 不对称烯烃与 HX 加成时 H 加在含氢较多的碳上 | ch03 |
| 芳香性 | 环状、平面、π 电子数为 4n+2 的体系具有的特殊稳定性 | ch04 |
| 手性碳 | 连有四个不同基团的碳原子 | ch04 |
| 对映异构体 | 互为镜像、不能重合的一对立体异构体 | ch04 |
| 外消旋体 | 等量对映异构体的混合物，旋光相互抵消 | ch04 |
